# Потеря буквы при повторном переключении в семействе окон, как у WeChat

Статус: QUEUED_AFTER_CURRENT_FIX. Приоритет: следующий запрос пользователя.
Дата: 2026-10-27. Делать самостоятельно, без агентов и Harness².

## Наблюдение пользователя

«в окне wechat есть прям баг если делать двойное перключение то в английской
версии седается буква после каждого переключения».

Уточнение: «WeChat не сам WeChat как таковой а все окна на базе WeChat».
Объём — класс окон с тем же механизмом ввода, а не исключение для имени процесса.
Что именно означает «английская версия» — пока не установлено; не приписывать
пользователю наблюдение о языке интерфейса приложения.

## Разбор до исправления

1. Зафиксировать релиз, реально загруженный IME/daemon SHA и способ подключения
   поля. Определить фактический GUI/input stack; имя приложения его не доказывает.
2. Подготовить отдельное тестовое поле того же типа. Не отправлять сообщения,
   не изменять чаты, аккаунты и настройки реального WeChat.
3. Сравнить незавершённое слово и слово после Space; 1, 2 и 5 последовательных
   Double Shift. Сохранять результат каждой пары, следующую букву и режим.
4. Найти первое расхождение по порядку press/release → decoder → документ →
   IME state → observed result. Не считать таймаут доказательством пропажи буквы.
5. Сопоставить с уже работающими соседними адаптерами. Общий root cause должен
   иметь один фикс; не добавлять условие `app == WeChat` и параллельного владельца.

## Минимальная приёмка

- Точный пример, baseline с потерей буквы и новый результат без потери.
- Каждое преобразование сохраняет полное слово, регистр, соседний пробел;
  следующая физическая буква соответствует реальному режиму.
- Удержанный обычный Shift работает; release не становится отдельным вводом.
- Не ухудшены текущие Chrome/Firefox/GTK/Qt/терминальные контроли затронутого пути.
- Скорость: median/p95/max и число образцов на установленной сборке.
- Scope тестов, неподтверждённое и runtime SHA записаны отдельно.

Текущая очистка FocusOut/Disable не объявляется причиной этого сбоя без
отдельного подтверждения. Карта влияния:
`docs/development/ime-impact-map-2026-10-27.md`.
