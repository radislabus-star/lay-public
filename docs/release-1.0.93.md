# Lay 1.0.93 — стабильные обновления и переключатель в меню

* «Автообновление» в меню GNOME и KDE: одна настройка пользовательского таймера,
  которую можно включить и выключить без перезапуска ввода.
* Проверка сравнивает установленный Lay с последним стабильным публичным
  релизом. Старая Git-ветка больше не создаёт ложное «обновлений нет».
* Ошибка сети или ответа сервера отображается как ошибка проверки.
* Обновлятор установлен независимо от рабочего каталога разработчика.
* Меню GNOME загружается и со старым загрузчиком, оставшимся в текущем сеансе;
  проверка обновления больше не принимает отсутствие работающего меню за успех.
* Фоновое обновление использует режим обновления существующей установки:
  без sudo, повторной настройки устройств ввода, регистрации IBus и очистки
  пользовательского обучения. Выключенный Lay не включается после сборки.

Включение: меню Lay → «Автообновление». Проверка запускается три раза в день с
небольшой случайной задержкой; пропущенная проверка выполняется после входа.
Отключение останавливает будущие проверки, уже начатая установка завершается.
Текущая поставка собирается из исходников; первая сборка может занять время.
Журнал: `journalctl --user -u lay-auto-update.service`.

Глобальный IBus не перезапускается. Уже работающий IME может оставаться прежней
версии до естественного завершения его сессии. Доказательства исходников и
установленного обновлятора приведены в
[протоколе](architecture/stable-auto-update-2026-10-19.md).
