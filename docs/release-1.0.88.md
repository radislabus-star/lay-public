# Lay 1.0.88 — готовится к выпуску

Исходники:3211/3211 PASS, MSRV1.88 обе конфигурации, строгие lints и
архитектурные проверки пройдены. GitHub CI, новые оконные результаты,
установка и выпуск проверяются отдельно. Пока установлен1.0.87.
[Текущий реестр доказательств](development/public-issues-2026-10-16.md).

Изменения после1.0.87:

- #59: сохраняются подтверждённые словарём формы глаголов с инфинитивами
  на `-ти`, включая `привезу`, `несу`, `везу`, `ползу`, `трясу`. Требуются
  известная лемма и точное применимое правило; одного окончания недостаточно.
  Подтверждение сохраняется при выборе раскладки в L2. Исключений для отдельных
  слов в runtime нет. [TD148](../tech_debt/148-recognize-backed-ti-present-forms.md).
- #46: добавлена отдельная настройка отмены последней автокоррекции по
  Backspace в IME, по умолчанию выключенная. Первый Backspace возвращает
  исходный текст, следующий удаляет обычно. Требуется точное текущее слово
  в том же поле. Чистый uinput не обещает отмену уже доставленного Backspace.
- #46: Double Space доступен для буквальной смены раскладки последнего слова.
  Оба пробела сохраняются, первый не задерживается. Double Shift остаётся.
  Для новых функций нужны согласованные daemon/IME/panel.
  [TD147](../tech_debt/147-explicit-undo-and-double-space.md).
- Исправлено сохранение точного подтверждения завершённого native replay
  через matched Reset при повторных переключениях. Также сохраняется готовая
  Space-коррекция, когда точный ответ поля приходит перед его Reset. Прежние
  проверки владельца, текста, поколения и единственный исполнитель сохранены.
  [TD150](../tech_debt/150-retain-completed-native-replay-across-reset.md),
  [TD151](../tech_debt/151-preserve-prepared-space-frame-on-matched-reset.md).
- #48: установщик использует session-scoped `uaccess` вместо постоянной группы
  `input`, сохраняет изменённые пользователем правила и отдельно проверяет
  активацию прав. Реальные ACL активного сеанса в этой задаче не испытывались.
  [TD146](../tech_debt/146-session-scoped-input-access.md).
- rustls обновлён0.23.45→0.23.46. На одной свежей базе RustSec число advisory
  уменьшилось с4 до0; остальные пакеты и политика аудита прежние.
  [TD149](../tech_debt/149-update-rustls-security-patch.md).
- CI сохраняет ограниченный фрагмент фактической ошибки при неожиданном
  отказе теста. Строгий набор проверок и нулевой реестр исключений сохранены;
  причина старого нестабильного отказа остаётся UNKNOWN.
  [TD152](../tech_debt/152-control-overlapping-release-test-readiness.md).

Сохранены восстановление позднего доступа к устройствам из1.0.87 (#49)
и обучение ручным возвратам: точный возврат защищает слово от повторной
коррекции, три отдельных подтверждённых возврата создают постоянное
пользовательское предпочтение. Обучения моделей и смены маршрутов доставки нет.

Сложные rich editors сохраняют известные FAIL/BLOCKED. Исходники и изолированные
удалённые браузеры не доказывают работу во всех приложениях и на локальной
физической клавиатуре. #47 остаётся открыт до нового результата автора на
Orange Pi после входа в сеанс. Финальные числа и скорости будут внесены только
из полного прогона совпадающих новых байтов, без выбора лучших строк.
