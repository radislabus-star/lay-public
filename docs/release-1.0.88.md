# Lay 1.0.88

В Lay 1.0.88 вошли:

- Отдельная настройка отмены последней автокоррекции по Backspace в IME. По умолчанию выключена; следующий Backspace удаляет обычно.
- Двойной пробел в списке сочетаний для буквальной смены раскладки последнего слова. Оба пробела сохраняются; Double Shift остаётся сочетанием по умолчанию.
- Сохранение подтверждённых словарём глагольных форм, включая «привезу» (#59), без исключений для отдельных слов в runtime.
- Сохранение подтверждения завершённого переключения и готовой Space-коррекции через Reset в Firefox.
- Права `uaccess` в установщике (#48), восстановление позднего доступа к устройствам из 1.0.87 (#49), rustls 0.23.46 и более точный отчёт ошибок CI.

Полный набор исходников: **3211/3211 PASS**, ноль исключений; Rust 1.88 MSRV, строгие lints и Security CI пройдены. Существующие маршруты доставки IME сохранены.

| Всего | 349 | 50 | 33 | 432 |

NOT_TESTED: 0 в этой матрице. Прежние успешные случаи сохранены. Double Shift: Firefox — медиана 98,5 мс, p95 111,4 мс (420/420 замеров); Chrome — 82,5 и 100,7 мс (406/420; 14 пропусков).

Дополнительные 80 случаев для новых сочетаний: **58 PASS, 18 FAIL, 4 заблокированных предусловия**. Отказы сохраняются в поисковых полях, contenteditable и iframe; часть возникает на проверке следующей буквы или возврате Backspace. Новые опции не включаются при обновлении. Их private/fullscreen-режимы NOT_TESTED. Модели и настройки пользователя сохраняются.

Это изолированный удалённый Wayland-стенд; Firefox использует прежний compatibility-helper. Универсальная работа во всех приложениях не подтверждена. #47 остаётся открытым для проверки запуска на Orange Pi после обновления. Реальные ACL активного сеанса установщика отдельно не проверялись.
