# Lay 1.0.88 — готовится к выпуску

Состояние: исходники проверены, GitHub Release и установка этой версии ещё
не выполнены. Установленная у пользователя версия —1.0.87.

- #59: распознаватель форм учитывает подтверждённые формы глаголов с
  инфинитивами на `-ти`, включая `привезу`, `несу`, `везу`, `ползу`, `трясу`.
  Требуются известная лемма и точное применимое правило словаря. Одного
  совпадения окончания недостаточно; неподдерживаемые/некорректные правила
  не дают нового основания для коррекции. Доказательство сохраняется и
  при выборе раскладки в L2. Словарные исключения для отдельных слов не добавлены.
- #46: отдельная настройка отмены последней автокоррекции по Backspace в IME
  (по умолчанию выключена) и Double Space для буквальной смены раскладки
  последнего слова. Оба обычных пробела сохраняются; первый пробел не задерживается.
  Обычный Double Shift и обучение ручным возвратам сохранены. Чистый uinput не
  обещает отмену уже доставленного Backspace; функции требуют согласованных
  daemon/IME/panel. Повторный Backspace после успешного отката удаляет обычно.
- #48: установщик использует session-scoped `uaccess` вместо добавления
  пользователя в постоянную группу `input`; изменённые пользователем файлы
  правил сохраняются. Новая активация прав проверяется отдельно от записи
  файлов. Реальные ACL активного сеанса в этой задаче не испытывались.
- Сохранено восстановление после позднего появления доступа к устройствам
  из1.0.87 (#49), а также существующее обучение ручным возвратам.
