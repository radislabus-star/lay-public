# Lay 1.0.103

Lay 1.0.103 исправляет запуск сборки при автообновлении.

- Установщик обновляет существующую службу автообновления до начала компиляции. Устаревший мягкий порог 3 ГиБ больше не задерживает сборку после обновления политики службы. Жёсткие ограничения 4 ГиБ RAM, одно ядро и 256 МиБ swap сохранены.
- Уже установленный пользовательский Rust подключается и тогда, когда в системе виден старый cargo. Новый Rust принудительно не устанавливается.
- Сохранены выбор автообновления, настройки и данные обучения. Обработчики ввода и маршруты доставки IME не изменены.

Проверено: 3 523 проверки корректности/упаковки, 11 проверок производительности, 421 Python-проверка (10 штатных пропусков), обе конфигурации MSRV и пять обязательных проверок GitHub. Собраны все десять оптимизированных программ без предупреждений компилятора. Настоящее автоматическое обновление на KDE прошло за 11 минут 20 секунд; десять установленных файлов сверены с артефактами Cargo. Для проверки до публикации использовались подготовленные метаданные релиза и закреплённый тестовый Git-источник; получение опубликованного релиза проверяется отдельно.

Текущий процесс IME сохраняет сессию ввода. Новых заявлений о совместимости всех окон этот установочный выпуск не добавляет; известные ограничения браузеров и семейства Qt остаются в списке задач.
