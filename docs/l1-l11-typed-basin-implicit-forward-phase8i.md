## 1. Decision

Phase 8H rejected the decoder-subtree representation, not the exact field
algebra. Its complete proof showed that lexical prefix topology does not factor
positional n-gram posting state enough to satisfy either the package or work
budget.

Phase 8I therefore does not invent another scheduler over global postings. It
changes the restoration admission contract explicitly:

```text
old research question
  exact global top-K over every WordCenter
  + typed terminal union

Phase 8I restoration question
  exact Phase 7D typed transducer over the complete decoder trie
  -> complete admissible restoration basin D_E(Q)
  -> candidate-local implicit depth-0 relation reconstruction
  -> exact activation for every terminal in D_E(Q)
  -> exact nonlinear settlement over D_E(Q)
  -> Winner | Tied | ABSTAIN
```

This is a semantic correction, not Phase 8H parity and not a hidden performance
optimization. A terminal outside the declared edit language is not a valid
competitor in the Phase 8I restoration lane merely because a global n-gram mass
places it in an arbitrary top-K.

The wave field remains the ranking mechanism. Typed geometry determines which
dictionary centers are admissible competitors; it does not assign the winner.

Phase 8I remains proof-only. It cannot change the installed package, runtime
authority, daemon, IBus, version, or production source route.

## 4. Admission Theorem And Claim Boundary

For the frozen dictionary W and edit language E:


Therefore an exact enumeration of D_E(Q) is a complete restoration admission

## 5. Depth-0 Forward Reconstruction

For center w and lexical atom i, encode `surface(w)` with the canonical
`encode_wave_surface` function and aggregate:

```text
n_i(w)  = number of occurrences of atom i in surface(w)
p_i(w)  = sum of normalized occurrence positions
S_i     = exact corpus occurrence support for atom i
N       = number of primary centers
```

Depth-0 compilation uses one clean surface per center, so:

```text
reliability_i(w) = n_i(w) * 255
specificity_i    = clamp(((N + 1) * 32) / max(S_i, 1), 32, 255)
strength_i(w)    = clamp(reliability_i(w) * specificity_i / 255, 1, 255)
position_i(w)    = min((p_i(w) / max(n_i(w), 1)) / 257, 255)
phase_i(w)       = clamp(position_i(w) - 128, -127, 127)
```

For every non-anchor atom with `n_i(w) > 0`, the implicit forward relation is:

```text
(peer_id=w,
 strength=strength_i(w),
 phase_relation=phase_i(w),
 position_mode=position_i(w),
 flags=0)
```

For observed query atom q_i, this relation contributes exactly the existing
four-coordinate activation event:

```text
mass          += strength_i(w) * q_i.weight
                 * position_coherence(q_i.position, position_i(w))
hits          += 1
surface_hits  += 1 for non-keyboard channels
keyboard_hits += 1 for keyboard channels
```

Thus the complete `ForwardActivation` for a terminal can be reconstructed from
the decoded surface, NGramGraph, exact atom support, and the query field without
reading a forward posting payload.

The proof implementation must reconstruct relation records independently and
compare all fields against the complete V8 postings. Comparing only mass, hit
count, cardinality, target rank, or final winner is insufficient.

## 6. Exact Support Is A Required Input

The initial shorthand `DecoderGraph + Atom.support + surface` is not exact for
the current package format. `AtomRecord.support` is stored as `u16`, while the
compiler computes support as a `u32` count of atom occurrences and saturates the
stored field at 65,535.

The immutable installed package contains:

```text
atoms                                      218,763
stored support == 65,535                       217
posting-bearing saturated atoms                180
no-forward saturated atoms                      37
```

Posting degree cannot substitute for exact support. Support counts occurrences,
whereas a forward posting has one relation per center containing the atom. The
baseline already contains 30 saturated posting-bearing atoms whose posting
degree is below 65,535.

Therefore the exact reconstruction input is:

```text
DecoderGraph
+ decoded surface
+ NGramGraph
+ exact u32 atom occurrence support
+ primary center count
```

Phase 8I proof rebuilds exact support once from every immutable decoded surface,
before reading heldout cases. It validates:

```text
stored_support[i] == min(exact_support[i], 65,535)
all encoded atoms resolve through NGramGraph
center and decoder counts remain unchanged
```

A future physical package must store exact values for saturated atoms. A simple
fixed-width projection costs:

```text
compact V7 base                            77,960,560 B
32-byte overflow header
217 * (u32 AtomId + u32 exact support)          1,736 B
projected compact package                 77,962,328 B
```

This is a projection, not a package round-trip. Phase 8I may measure it but may
not create V9 or mutate the current V8 artifact.

## 7. Reverse State And Nonlinear Settlement

Forward activation parity is necessary but not sufficient. Existing nonlinear
settlement also consumes candidate-local reverse state, center wave code,
sequence anchors, geometry, normalization maxima, and candidate interactions.

The compact reverse relation is also deterministic from the surface and exact
support, followed by the existing anchor-first order and lexical truncation.
The current V8 lazy runtime reconstructs reverse strength from the saturated
`u16` field. That behavior cannot be assumed to equal the original compiler
semantics for the 217 saturated atoms.

Phase 8I must therefore keep two references visible:

```text
V8 live-behavior fingerprint
  current saturated-u16 reverse reconstruction

compiler-exact depth-0 fingerprint
  exact-u32 support for forward and reverse reconstruction
```

If they differ, the proof reports the first shared mechanism and quality impact.
It must not silently call one fingerprint parity with the other. Production
behavior cannot change in the same step as the reconstruction proof.

Within the Phase 8I restoration lane:

```text
max_forward = max activation mass over complete D_E(Q), clamped to at least 1
```

Using a maximum from an inadmissible global center would preserve the rejected
global-search semantics through normalization. Using only a truncated subset of
D_E(Q) would make settlement incomplete. Both are forbidden.

The finalizer order remains unchanged:

```text
candidate settlement
-> restoration geometry
-> structural interference
-> pairwise interference if present
-> sequence certificate interference
-> package pairwise field if present
-> candidate ordering
-> geometry certificate interference
-> position certificate interference
-> restoration classification
```

The current depth-0 compact base has no learned positive, anti, hard-negative,
ambiguity, or pair residual banks. Phase 8I must still prove this from the loaded
package and fail closed if a future package introduces unresolved dependencies.

### 7.1 A2 Single-Fingerprint Contract

A2 is not allowed to pass exact forward activation into the ordinary V8
settlement route. That route obtains reverse relations lazily from
`AtomRecord.support`, whose compact value is saturated at `u16::MAX`. Such a
call would create an unlabelled mixed fingerprint:

```text
exact-u32 implicit forward
+ saturated-u16 V8 reverse
-> invalid A2 result
```

The compiler-exact A2 route is one end-to-end fingerprint:

```text
complete typed basin D_E(Q)
-> implicit exact-u32 forward activation for every terminal
-> max_forward over all D_E(Q), clamped to at least 1
-> exact-u32 reverse relation bank for every terminal in D_E(Q)
-> settlement using the matching explicit reverse slice
-> restoration geometry using that same explicit reverse slice
-> dependency-audited finalization
-> dependency-audited phase evidence
-> restoration classifier
```

The current V8 compatibility route is computed separately:

```text
the same D_E(Q)
-> the same forward activation and max_forward
-> current saturated-u16 V8 reverse reconstruction
-> the same frozen settlement/finalization order
-> restoration classifier
```

The two outputs may differ. Such a difference is a measured migration fact, not
an A2 parity failure and not permission to change production authority.

### 7.3 Package Dependency Audit

Before the first candidate is settled, A2 records and validates all package
dependencies that can affect finalization:

```text

positive subcenters
anti subcenters
hard-negative subcenters
ambiguity subcenters
keyboard geometry units

```

The audit reports physical vector lengths and summed referenced counts
separately. Empty vectors with non-empty references, or non-empty vectors not
owned by an A2 adapter, are errors. Keyboard geometry is not a learned residual
bank and may remain package-backed because it does not reconstruct reverse
state. Any learned bank that needs owner/competitor reverse relations requires
an exact-provider adapter before A2 can continue.

### 7.4 Compiler Reference And Permutation Proof

The exact reverse producer is compared relation-for-relation with an independent
compiler-formula reference over the same decoded surface and exact support:

```text
peer_id / strength / phase_relation / position_mode / flags
anchor-first ordering
MAX_REVERSE_LEXICAL_COUPLINGS truncation
```

Settlement parity then compares the complete candidate state, final candidate
order, and serialized `Winner | Tied | ABSTAIN` readout. The proof runs the same
basin in forward and reversed terminal order. Both the compiler-exact and V8
fingerprints must be internally permutation invariant; equality between the two
fingerprints is reported but not assumed.

A2 stops before settlement on any of these conditions:

```text

unresolved learned package bank

```

Coefficients, calibration, basin membership, candidate limits, and the installed
package remain frozen during this work.

### 15.2 Fixed Objective And Metric Semantics

The selected damaged surfaces and their objective terminal sets are prepared
before quality execution from the immutable full corpus using the existing
fixed heldout reservoir and sampled-ambiguity builder. Objective labels are
read only after candidate settlement. They may update counters and diagnostics;
they may not affect traversal, reconstruction, `max_forward`, settlement,
ordering, classification, or candidate limits.

```text
target retention
  fixed target terminal occurs anywhere in complete D_E(Q)

lattice coverage
  fixed target terminal occurs in the first 64 final settled candidates

unique top-1
  objective set has exactly one terminal and final candidate rank 1 is it

false authority
  RestorationReadout::Winner is outside the complete objective set

false singleton
  RestorationReadout::Winner is emitted while geometric_basin(candidates)
  contains more than one terminal

clean preservation
  clean terminal is final rank 1 and no Winner mutates it to another terminal

grounded legacy candidate
  a current V8 top-64 candidate carrying non-zero reconstruction_modes

grounded legacy candidate loss
  such a candidate is absent from compiler-exact D_E(Q)
```
