# Lay 1.0.89

- Double Space сохраняет точное число обычных и неразрывных пробелов при смене раскладки последнего слова в редактируемых блоках и iframe.
- При подтверждении результата предыдущий текст отделён от заменяемого слова: префикс строки сохраняется точно.
- Согласованы номера CLI, daemon, IME и панели: 1.0.89. Маршруты доставки IME, модели и настройки пользователя сохранены.

Исходники: **3211/3211 PASS**, ноль исключений; Rust 1.88 MSRV, строгие lints, CI и Security с первой попытки на функциональном коммите `8562c2bb`. Финальное независимое ревью — 9/10. После проверки изменена только константа версии панели; точное соответствие остальных 992 файлов и трёх бинарных файлов ядра подтверждено отдельно. Функциональные проверки повторно не запускались.
