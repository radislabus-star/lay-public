# Lay 1.0.96

Эта версия исправляет запуск после входа в рабочий стол, совместимость с
GNOME 51 и общий участок кода, через который особенности KDE затронули другие
среды. Установщик показывает краткий прогресс сборки и сохраняет полную
диагностику в журнале.

## Исправления

- **Запуск после входа (#69, последний описанный сбой #47).** Демон и служба
  L3 привязаны к `graphical-session.target`. При обновлении старые связи с
  `default.target` пересоздаются; выключенные пользователем службы остаются
  выключенными. Миграция файлов служб сама не останавливает текущий ввод.
- **GNOME 51 (#63).** Виртуальная клавиатура использует backend контекста
  сцены. Для прежних поддерживаемых версий сохранён их API. Исправлено также
  создание вертикального блока последних действий после удаления `vertical`
  в новом St.
- **Разделение сред.** Правило KDE об отправке набранного префикса обычным
  текстом выбирается через существующий механизм определения среды.
  GNOME, X11 и Niri сохраняют свой прежний контракт композиции.
- **Первый ответ приложения после передачи слова.** Текущее разрешение
  сохраняется до смены признака первого callback и затем проходит прежние
  проверки текста, владельца, ревизии и срока действия.
- **Память английского словаря.** Дубликаты удаляются до выделения строк
  итогового словаря. Полный состав, порядок и отпечаток словаря проверяются
  против предыдущего построения. Замер дополнительной RSS: 15420 → 13672 КиБ
  при прежнем лимите 15360 КиБ; проверка ресурса проходит.
- **Сборка и диагностика.** В окне установки остаются прогресс, итоговое
  число предупреждений и путь к полному журналу. При ошибке выводится вся
  диагностика и сохраняется исходный код отказа. Удалены неиспользуемые
  импорты и лишняя обёртка; строгая проверка известных исследовательских
  предупреждений сохранена. Линтер теперь показывает причины неудачной
  компиляции до удаления временного журнала.
- **Безопасность зависимостей.** Точечно обновлены rustls-webpki до 0.103.16,
  webpki-roots до 1.0.10 и Tokio до 1.53.3.

## Проверка

Пройдены 3511/3511 тестов корректности и пакетов, 11/11 проверок скорости и
ресурсов, обе конфигурации MSRV Rust 1.88, строгие проверки предупреждений и
аудит безопасности без уязвимостей. Все десять устанавливаемых программ
собраны и установлены на удалённый KDE; номера CLI, демона и IME совпадают.
Публикация ещё ожидает фактического CI и проверки стабильного обновлятора.
Текущие результаты и точные пути к доказательствам ведутся в
[плане работ](development/weekend-repair-plan-2026-10-24.md).

Эта версия не подтверждает полную совместимость KDE. Новый оконный прогон
Chrome: 168 PASS / 10 FAIL / 42 BLOCKED из 220. Firefox с доступностью,
включённой только для тестового процесса: 81 PASS / 103 FAIL / 36 BLOCKED из
220. Без этой подготовки наблюдатель Firefox заблокирован до ввода. Отказы
браузеров сохраняются в доказательствах; их нельзя заменять результатом
тестов исходников. GNOME 51 на настоящей машине и Orange Pi не проверены.
