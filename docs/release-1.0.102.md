# Lay 1.0.102 — сохранение актуального фокуса при завершении старого слова

Исправлен доказанный тестами сбой порядка событий FocusOut/Disable: повторное
завершение уже отозванного старого слова могло стереть сведения о следующем
поле ввода. Теперь завершается только старое слово; новые сведения о фокусе
сохраняются. Сохраняется и штатный возврат режима раскладки после Disable.
Старое разрешение редактировать текст не восстанавливается.

Изменены две точные ветви общего обработчика жизненного цикла IME. Маршруты
доставки, исполнители, проверка права на замену, модели и оформление KDE/GNOME
сохранены. Это общий ремонт порядка событий; он не объявляется исправлением
всех отказов конкретного браузера. Надёжный ручной способ воспроизвести именно
доказанный тестом порядок событий пока не установлен.

Проверены 3523/3523 проверки корректности и пакетов, 11/11 проверок
производительности, 419 Python (10 пропусков, без ошибок), линтеры, MSRV1.88
в двух конфигурациях и все10 оптимизированных устанавливаемых программ.
