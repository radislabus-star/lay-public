## Consequences and invariant boundaries before production edits

- Retention: preserve all grounded L1.1 material and existing exact authority.
  Correct child-prefix material replaces an incomplete cache shortcut; quantify
  bounded-lattice gains AND losses across the frozen full panel, not one word.
- Ranking/authority: cache repair changes supplied evidence, so admission and
  resulting choices require proof. Semantic ordering must preserve original
  admissions, evaluations and verifier inputs; L4 remains an independent signal.
  Do not adjust safety or authority to conceal a missing target.
- Latency/tails: current-prefix traversal can cost more than projection. Measure
  warm/cold p50/p95/p99, maximum, cache behavior and150ms publication budget;
  no per-key corpus scan, LM RPC or unbounded decoder traversal.
- CPU/RSS/allocations: retain existing hard traversal/material/cache limits;
  test dense, decoder-only, mixed-script and long prefixes. No new worker,
  timer or cache is selected. Compiler/model work stays guarded remotely.
- Identity/reload: use the existing immutable lexical package and exact
  prefix/limit/mode cache identity. Canonical/productive generation and live
  cache invalidation remain untouched. New schema/package compatibility is
  not implied by an unchanged function name.
- Learning: candidate generation/order never becomes positive feedback. Keep
  confirmed-user and confirmed-attested-boundary outcomes separate from mere
  display. Controlled L4 tests use private paths, never personal live updates.
- Concurrency: current worker and revision lease reject obsolete results;
  no state survives new focus or Reset through a new owner or fallback.
- Failure/rollback: absent/invalid data remains unavailable. Preserve exact
  installed1.0.78 binaries/config/models before any hot upgrade; rollback those
  bytes, not a rebuilt substitute. No global IBus restart or source migration.
- Compatibility: shared library consumers, correction, completion, Space,
  Tab, held Shift and Double Shift retain their distinct existing routes.
  Renderer/gesture/output protocols are outside the semantic change.
- Maintenance: remove the unsound projection shortcut rather than introduce
  another cache. Replace/extend the existing L3 owner if justified, preserving
