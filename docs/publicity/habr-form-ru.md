## Лид

`lay` — маленькая open-source утилита для Linux: набрал слово не в той RU/EN
раскладке, нажал Shift два раза, слово перепечаталось правильно. Основной
сценарий локальный, без облака и обязательной LLM.

## Короткое описание

Локальный keyboard helper для Linux desktops: double Shift переворачивает слово,
набранное не в той RU/EN раскладке. Основной путь работает без облака, буфера
обмена и LLM. GNOME — основной путь, KDE Plasma и X11 уже поддержаны.
