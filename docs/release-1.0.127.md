# Lay 1.0.127 — автокоррекция по контексту

При пропуске буквы в русском инфинитиве Lay учитывает предыдущие слова, когда словарь допускает две формы и контекст даёт основание выбрать одну.

- `мы продолжаем улучшть` → `мы продолжаем улучшать`.
- `мы успели улучшть` → `мы успели улучшить`.
- `нам нужно улучшть` остаётся как введено. Здесь подходят обе формы.

Lay повторно использует рассчитанные расстояния редактирования при выборе кандидатов. Он также отклоняет слабо подтверждённый перенос буквы через пробел, если предыдущая форма подтверждена и есть однословный кандидат с внутренним пропуском.

На стенде 13 из 242 случаев получили новое правильное решение о замене. Семь из них взяты из отложенных размеченных текстов. Новых неверных замен в этом прогоне не было. Все 13 решений были готовы в пределах 80 мс вычисления. Исходники прошли 3652 проверки.

Проверка охватывает указанные классы опечаток. Обновление доступно через «Проверить обновления» в меню Lay.

Зависимость `rustix` обновлена до `1.1.6`. [Бюллетень RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0486).

Манифест учитывает пример `fragment_prefix_proof` из публичной ветки. Все 3708 тестовых записей сохранены. [Отчёт подготовки выпуска](development/evidence/release-1.0.127-verification.json).
