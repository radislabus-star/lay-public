# Lay 1.0.128 — перевод выделенного текста

Выделите фрагмент, вызовите `lay --selection` и вставьте результат из буфера
обмена. Команду можно назначить сочетанию клавиш в настройках рабочего стола.
Если приложение не передаёт выделение в X11, скопируйте нужный текст и вызовите
`lay --clipboard`.

Например, `[jxtim ddtcnb` преобразуется в `хочешь ввести`. Преобразование
работает в обе стороны. В Linux штатный `xclip` сохраняет результат после
завершения команды, в том числе в сеансе без менеджера буфера.

На отдельном стенде GTK3/X11 прошли шесть проверок. Вставка меняла только
выделенный фрагмент. Отсутствие выделения или `xclip` оставляло буфер доступным
с прежним содержимым. Проверка охватывает команды и вставку в поле GTK3.
Обновление доступно через «Проверить обновления» в меню Lay.
